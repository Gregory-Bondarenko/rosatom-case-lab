# Rosatom Case Lab

Решения домашних заданий кейс-лаборатории по ML в рамках ИТ КоР от Росатома. Все работы сданы и проверены в рамках программы

Каждое задание лежит в своей папке: ноутбук с условием, решением, пройденными проверками и выводами, рядом короткий README с главными результатами. Ноутбуки сохранены вместе с выводами, их можно читать прямо на GitHub без запуска

| [01-pytorch-autograd](./01-pytorch-autograd) | Тензоры и автоматическое дифференцирование | Векторные операции без циклов, логистическая регрессия на чистом autograd, проверка градиентов численными разностями, устойчивый Softplus через `autograd.Function` |

## Как устроены решения

Условие каждой задачи оставлено как есть, решение идёт сразу под ним. Почти везде есть блок `assert`: результат сверяется не сам с собой, а с аналитической формулой, эталонной реализацией из библиотеки или независимо написанной версией. После кода идут выводы, в которых разобрано, почему результат именно такой и где у метода проходят границы

Местами решение выходит за рамки условия, если без этого вывод был бы неполным: например, сравнение с регуляризацией там, где без неё задача не имеет единственного решения, или контрольный вариант с заведомой ошибкой, чтобы показать, что проверка её ловит

## Как запустить

Все задания считаются на CPU за несколько минут, данные синтетические или встроены в `sklearn`, скачивать ничего не нужно

```
python -m venv env
source env/bin/activate
pip install -r requirements.txt
jupyter lab
```

Для задания 03 нужен компилятор `gcc`/`g++`: в Linux и Google Colab он есть, под Windows удобнее запускать через WSL или Colab

Проверено: все ноутбуки выполняются с нуля сверху вниз, все проверки проходят. Python 3.11, torch 2.14, numba 0.68, Cython 3.3, pybind11 3.1, tensorly 0.9, scikit-learn 1.9, gcc 13. Время в таблицах замеров зависит от машины, соотношения между вариантами сохраняются

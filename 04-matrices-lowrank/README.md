# 04. Матрицы в PyTorch: малоранговые представления

Ноутбук: [matrices_lowrank.ipynb](matrices_lowrank.ipynb)

## Задачи

- **1.1.** SVD-сжатие изображения и проверка теоремы Эккарта-Юнга, в том числе против факторизации, обученной градиентным спуском
- **1.2.** Восстановление зашумлённой малоранговой матрицы усечением SVD
- **1.3.** Плохо обусловленная система и регуляризация через усечённую псевдообратную
- **2.** Randomized SVD для матрицы 2000×1500

## Что получилось

- Ошибка rank-k приближения совпадает с хвостом сингулярных чисел до 1e-15 относительной разницы. Градиентный спуск по той же метрике из трёх инициализаций останавливается на 0.02–6% выше SVD и ни разу её не превосходит
- При денойзинге оптимальное k = 5 при истинном ранге 10: слабые компоненты ниже края шумового спектра восстанавливать невыгодно. Порог Гавиша-Донохо даёт то же k без знания чистой матрицы, ошибка в 5 раз меньше, чем без денойзинга
- При cond(A) = 1e12 `linalg.solve` ошибается в 6.9e5 раз, усечённая псевдообратная при k = 10 даёт ошибку 4.9e-6. Тихонов с лучшим λ здесь примерно в 40 раз хуже усечения. Для произвольного x_true лучшее k смещается к 100, туда, где σ_k опускается до уровня шума
- Randomized SVD при двух степенных итерациях быстрее полного примерно в 70 раз при относительной ошибке сингулярных чисел 2e-15. Без ортогонализации между итерациями базис вырождается, и угол с истинным подпространством доходит до 87°

# 07. CNN, часть 2: transfer learning и сегментация

Ноутбук: [cnn_transfer_segmentation.ipynb](cnn_transfer_segmentation.ipynb)

Для transfer learning используется подвыборка EuroSAT (6000 / 1500 / 1500, вход 128×128), для сегментации Oxford-IIIT Pet (около 800 МБ). Датасеты и веса ResNet18 скачиваются автоматически при первом запуске. Выводы в ноутбуке получены в Colab на GPU T4

Во вступлении к заданию перечислены задачи до 3.3, но в выданном ноутбуке есть только 1.1, 1.2 и 2.1. Наивный baseline, на который ссылается 2.1, собран прямо в её решении

## Задачи

- **1.1.** ResNet18 с нуля против ImageNet-весов при одинаковом бюджете
- **1.2.** Стратегии заморозки: только `fc`, `layer4` + `fc`, полное дообучение
- **2.1.** U-Net с нуля для бинарной сегментации «питомец / фон» и абляция skip-связей

## Что получилось

- С ImageNet-весами 0.945 на тесте против 0.772 с нуля за 8 эпох. Уже после первой эпохи предобученная сеть (0.943) выше, чем сеть с нуля в конце обучения, а до 0.8 val accuracy сеть с нуля за этот бюджет не доходит вообще
- Разморозка `layer4` закрывает весь разрыв с полным дообучением (0.957 против 0.959) при 8.4 млн обучаемых параметров вместо 11.2. Отдельно показано, что `requires_grad=False` не замораживает BatchNorm: если backbone не перевести в `eval()`, бегущие статистики дрейфуют, и test падает с 0.893 до 0.871
- U-Net даёт IoU 0.813 против 0.501 у центрального прямоугольника и 0.324 у предсказания «всё питомец». Граничные пиксели исключены из лосса и метрики, флип делается одним решением для картинки и маски
- Абляция skip-связей (0.813 против 0.807) ничего не доказывает: val IoU внутри одного прогона скачет до 6 пунктов, а два запуска одной конфигурации разошлись на 5. Для вывода нужны несколько сидов и лучший по валидации чекпоинт

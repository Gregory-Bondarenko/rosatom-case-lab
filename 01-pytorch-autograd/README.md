# 01. Тензоры и автоматическое дифференцирование

Ноутбук: [pytorch_autograd.ipynb](pytorch_autograd.ipynb)

## Задачи

- **1.1.** Нормализация столбцов, попарное косинусное сходство и one-hot с игнорируемой меткой только тензорными операциями, без циклов
- **1.2.** Логистическая регрессия на `load_breast_cancer` без `torch.nn` и `torch.optim`: ручной градиентный спуск и своя BCE, сравнение с `sklearn`
- **1.3.** Численный градиент прямой и центральной разностью против autograd, поиск ошибки в ручном градиенте
- **2.** Численно устойчивый Softplus как `torch.autograd.Function` со своими `forward` и `backward`

## Что получилось

- Стандартизованный breast_cancer линейно разделим, поэтому без регуляризации минимума логлосса нет и веса уходят в бесконечность: у GD норма около 11, у sklearn около 59 тысяч при одинаковой accuracy. С одинаковой L2 в обоих методах веса совпадают до 1e-4, accuracy 0.988
- Шаг спуска не подбирался, а взят как 1/L через константу Липшица градиента, BCE записана через логиты без `log(0)`
- Ошибка численной производной минимальна при ε ≈ 1e-8 для прямой разности и 1e-5 для центральной во float64, во float32 при 1e-3 и 1e-2. Ниже этих значений ошибка снова растёт из-за округления, и это видно в таблице
- В задаче с багом потеряна производная слагаемого x₀·x₂ по x₀. Исправленная версия дополнительно сверяется с центральной разностью
- Softplus записан одной формулой max(x, 0) + log1p(e^(−|x|)), проходит `gradcheck` и на x = 1000 даёт конечные значение и градиент, где наивная версия даёт inf и nan

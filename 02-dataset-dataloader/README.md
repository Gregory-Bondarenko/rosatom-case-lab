# 02. Dataset, DataLoader и корректная работа с данными

Ноутбук: [dataset_dataloader.ipynb](dataset_dataloader.ipynb)

## Задачи

- **1.1.** Свой `Dataset` для табличных данных с z-нормализацией и гауссовым шумом как аугментацией
- **1.2.** Стратифицированный train/test split и проверка, насколько ошибается наивный случайный сплит на редком классе
- **1.3.** Веса для `WeightedRandomSampler` при произвольном числе классов
- **2.** `collate_fn` для пар параллельных последовательностей переменной длины с общей маской паддинга

## Что получилось

- Валидационный датасет нормализуется статистиками train, а не своими, иначе в нормализацию утекает информация о самой валидации. Шум добавляется ровно заданной величины, std разности 0.1007 при `noise_std=0.1`
- Стратифицированный сплит сделан без цикла по классам. Наивный сплит с test из 100 объектов ошибается в доле редкого класса в среднем на треть от неё самой, в 12.7% сплитов доля уходит вдвое, в 0.5% класса в test нет вообще. Разброс совпадает с гипергеометрическим законом
- Сэмплер выравнивает доли классов в батчах до трети, но с `replacement=True` больше 60% объектов мажоритарного класса за эпоху не попадают в батчи ни разу
- Паддинг собран без `pad_sequence`: маска строится один раз из длин, и обе последовательности записываются по ней, поэтому синхронность гарантирована способом записи, а не проверкой после
